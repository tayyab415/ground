# District geometry

`up-rice-districts.geojson` is a simplified extract of Uttar Pradesh district polygons from [udit-001/india-maps-data](https://github.com/udit-001/india-maps-data) (Uttar Pradesh GeoJSON). That compilation credits DataMeet / Survey of India index maps. It is **not** an official Survey of India product.

V1 keeps twelve eastern rice-belt districts so ranking can be sourced. This is not a 75-district census map.
